Athena — the thread through all 24 weeks

A document intelligence platform. It ingests a corpus, indexes it, searches it, answers questions with citations, and runs multi-step research with an agent — knowing what it costs and proving it hasn't regressed. The loop, every session

  1. Read the relevant section of the module's LESSON.md.
  2. Run the matching file in examples/ — then edit it and break it, so you learn to read the traceback.
  3. Open the exercises/ file and implement the functions. The docstring is the spec; do not open the test first.
  4. Run the tests until green.
  5. Run ruff and mypy. Green there means idiomatic and type-safe, not merely correct.
  6. Reread your own solution and ask what a comprehension, a key=, or a Counter would delete. That question, asked every time, is how fluency happens.
